# 00 - Overview

## Objetivo
Estabelecer um scaffold enterprise-ready para um Customer Support Agent com separação clara de camadas e baixo acoplamento.

## Princípios
- Clean Architecture
- Ports and Adapters
- Evolução incremental e revisável
- Observabilidade desde o início

## Escopo desta entrega
- Estrutura de projeto
- Configuração de execução/testes
- Documentação arquitetural inicial
- Sem lógica de negócio implementada
